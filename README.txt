CARA PAKAI
1. Buka folder RenEsp di Android Studio (Koala/Ladybug), tunggu Gradle sync.
2. Download model efficientdet_lite0.tflite (TFLite Hub / Kaggle: "efficientdet lite0 detection metadata")
   lalu taruh di: app/src/main/assets/efficientdet_lite0.tflite
3. Colok HP (USB debugging) lalu Run.
Catatan: jarak = perkiraan dari tinggi kotak; ubah vFovDeg di MainActivity.kt untuk kalibrasi.
